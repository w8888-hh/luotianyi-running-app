## 三、怎么生成洛天依声音

1. **GPT-SoVITS（推荐，说话最自然）**
   - 找洛天依声线的 SoVITS 模型（社区有 `LuoTianyi` 语音模型），本地起 TTS 接口
   - 逐句合成 → 导出 mp3 → 按上表命名放入 `voices/`
2. **ACE Studio（洛天依 AI 官方）**
   - 桌面端软件，用洛天依 AI 音色朗读导出
3. **VOCALOID（你自己会用）**
   - 用洛天依声库调出这几句（注意是「说话」语气，可加 talkloid / 调整参数），导出 wav 转 mp3

## 四、放入后如何验证

1. 把 mp3 放进 `running_app/voices/`
2. 打开页面，点「试听提示音」——应播放洛天依版本而不是系统 TTS
3. 控制台无报错即可

## 五、运行说明

- Web Bluetooth（心率）要求**安全上下文**，必须用本地服务打开，不能用 `file://` 直接双击：
  ```bash
  cd running_app
  python -m http.server 8000
  # 浏览器打开 http://localhost:8000
  ```
- 心率功能仅 Chrome / Edge / 安卓 Chrome 支持；iOS Safari 不支持（后续上安卓/鸿蒙不受影响）
