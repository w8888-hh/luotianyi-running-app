# 洛天依陪跑 v1.2 更新 —— 天依可以跟着你跑，也可以听你的

> 一个开源、免费、无广告、不联网的跑步陪伴 App。洛天依在你耳边说话，按节拍带你跑。

---

## 先说这次最值得试的三件事

**一、你可以自己定步频了**

以前只有两种模式：天依带你跑（她定节奏），或者天依跟你跑（她看你心率）。现在多了第三种 —— **你自己定**。

设定一个 BPM，节拍器全程就按这个值走，不分阶段、不随心率变速、也不会自动结束。想跑多久跑多久。

跑步页顶部有个绿色胶囊显示当前步频，**跑的过程中点一下就能改**。跑着觉得快了就降两拍，状态来了就往上加，改完当拍生效，不用停表。

范围 60–220，还给了六个常用档位：轻松 150 / 慢跑 160 / 节奏 170 / 快跑 180 / 冲刺 190 / 间歇 200。

**二、「天依跟你跑」不再一惊一乍**

这是之前体验最糟的地方：心率跨区间时，节拍器会一步跳十几拍，脚下一乱节奏就没了。

现在改成渐进的 —— 每秒最多变 2.5 拍，慢慢把你带到该去的速度。你加速，它跟着加一点；你稳住，它就不动；到位之后完全稳定，不会再抖。

跑步页会显示 `BPM 165 → 172`，你能清楚看到天依正把你往哪个节奏带。

**三、节拍器不再是电子「哔」**

原来那声音确实机械 —— 代码里就一个方波振荡器，单个音高，50 毫秒就没了。

现在换成三层合成：一段白噪声过带通做敲击瞬态，一个三角波做共鸣体（起音频率会往下滑，这是"被敲了一下"的关键），最后过一道低通把刺耳的高频削掉。听感接近木鱼，柔和很多。

如果你就喜欢原来那种清脆的电子音（户外嘈杂时确实更听得清），均衡器面板底部可以切回去，点一下会先示范两拍。

## 完整的更新清单

### 跑法

- 新增「自定义 BPM」跑法，跑步中可随时调整
- 「跟天依跑」的四阶段占比可以调：总时长还是等于歌单总长，但热身 / 燃脂 / 冲刺 / 放松各占多少由你定。改一根滑块，其余三根自动重分，合计恒为 100%
- 「天依跟你跑」的节拍器改为渐进靠拢，不再瞬跳
- 引导跑实时显示阶段时间：第几阶段、本阶段还剩多久、距下一阶段还有多久、全程还剩多久

### 音乐

- 开跑时音乐跟节拍器一起起来（以前要暂停再继续才出声）
- 批量导入大幅提速，实测快 58%–78%：40MB 单文件从 3.7 秒降到 1.6 秒
- 导入的音频会持久化，重启 App 不用重新导
- 不需要的歌可以「移除」，只出歌单、不删本地文件，之后还能加回来
- 内置专辑里长按一首进入多选，一次把整张专辑加进来
- 跑完会问你要不要把这次听过的歌存成歌单
- 点已存歌单先进详情页（封面 / 名称 / 歌手 / 时长），不再直接就开始播

### 通知栏

- 跑步时常驻通知条：时长、距离、配速、心率、BPM、阶段、当前曲目
- 五个图标按钮：上一首、播放暂停、下一首、暂停·开始运动、结束运动。图标随状态切换，跟实际播放状态实时同步
- 锁屏也能直接用

### 修掉的坑

- **点击开始跑步后闪退**（Android 14 机型必现）：前台服务类型声明和调用方式不匹配，加上通知权限没兜住，两个问题叠在一起直接崩进程。已修
- 语音播报慢半拍：每句话前都要重新探测一次音频文件（第一条必然 404），现在会缓存
- 通知条在部分 ROM 上出不来：布局里用了 RemoteViews 不支持的控件

APK 在 GitHub Releases 里（仓库不放安装包，太大）：

```

```

源码也在这里：<https://github.com/w8888-hh/luotianyi-running-app>（MIT 协议，随便改随便分发）

安卓 8.0 以上都能装。第一次开跑会要通知权限，给了才有常驻通知条；不给也不影响跑步，只是没有通知条。

心率功能要连蓝牙手环或心率带。不连也能跑，只是「天依跟你跑」会退回按时间推进。

## 关于开源

整个项目 MIT 协议开源，代码在 GitHub 上，你可以随便改、随便分发，只要保留版权声明就行。

顺带说明几个大家可能关心的点：

- **数据全部在你手机本地**，没有服务器、没有账号、没有埋点统计，也没有广告
- 跑步记录、心率历史、你自己导入的音乐，一样都不会离开你的设备
- 代码公开，隐私相关的实现可以直接翻代码核对

洛天依的语音是本地音频文件（16 句，阶段提示 + 控制语音 + 8 句随机鼓励）。仓库里带的是示例语音，想换成自己合成的音色，把同名文件放进 `voices/` 目录就行，脚本清单在 `voice_script.md`。
