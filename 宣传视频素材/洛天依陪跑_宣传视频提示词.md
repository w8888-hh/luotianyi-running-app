# 洛天依陪跑 — 宣传 Demo 视频制作提示词

## 一、视频主题

介绍「洛天依陪跑」—— 一款让虚拟歌手洛天依陪你跑步的智能运动 App，面向喜欢二次元、想要有趣跑步体验的年轻用户。

---

## 二、内容结构（45 秒完整版）

### 1. 开场（5 秒）
- **标题**：「洛天依陪跑」
- **副标题**：「让天依陪你一起跑」
- **画面**：洛天依跑步剪影 + App 图标 + 橙色音符飘动
- **背景**：深空蓝（#13121C）到橙色（#FF8C42）的渐变光晕
- **配音**：「准备好啦～三、二、一，跟天依一起出发吧！」（使用 `voices/zhunbei.wav`）

### 2. 第一部分：语音陪伴（10 秒）
- **要点**：洛天依真人语音全程陪伴跑步
- **画面**：跑步页界面 + 语音气泡弹出「先慢慢跑哦，跟着天依的节奏，深呼吸～」
- **图标**：音符 + 语音波形动画
- **配音**：「先慢慢跑哦，跟着天依的节奏，深呼吸～」（使用 `voices/reshen.wav`）
- **字幕**：白色，居中，每句不超过 15 字

### 3. 第二部分：智能训练（10 秒）
- **要点**：四阶段科学训练 + 心率驱动自动切换
- **画面**：阶段条动画（热身 → 燃脂 → 冲刺 → 放松）+ 心率环实时跳动
- **图标**：四个阶段图标依次高亮
- **配音**：「进入燃脂区啦，保持节奏，脂肪在燃烧哦～」（使用 `voices/ranzhi.wav`）
- **字幕**：「热身 · 燃脂 · 冲刺 · 放松」+ 「心率智能驱动阶段切换」

### 4. 第三部分：音乐节拍（10 秒）
- **要点**：内置洛天依专辑 + BPM 节拍器自动匹配
- **画面**：音乐播放器界面 + 专辑封面轮播 + 节拍波纹扩散
- **图标**：音符 + 节拍波纹
- **配音**：「很棒很棒，就是这个节奏！」（使用 `voices/henbang.wav`）
- **字幕**：「内置四重奏专辑 · BPM 节拍器 · 智能推荐」

### 5. 第四部分：设备连接（5 秒）
- **要点**：蓝牙连接手环/手表，实时心率监测
- **画面**：蓝牙扫描界面 + 设备列表 + 心率数据实时接入
- **图标**：蓝牙图标 + 心率曲线
- **字幕**：「蓝牙连接手环 · 实时心率监测」

### 6. 结尾 CTA（5 秒）
- **标题**：「下载洛天依陪跑，和天依一起跑起来！」
- **画面**：App 二维码 / 应用商店图标 + 洛天依挥手
- **背景**：橙色渐变 + 粒子飘动
- **配音**：「训练完成啦！天依觉得你好棒，记得拉伸放松哦～」（使用 `voices/jieshu.wav`）

## 七、约束条件

1. **动画简洁**：只用淡入淡出、位移、缩放，不用复杂 3D 或粒子特效（除背景极光）
2. **文字精简**：每屏主标题不超过 8 字，说明文字不超过 15 字
3. **图标易懂**：使用通用图标（音符、心、蓝牙、跑步人形），不抽象
4. **品牌一致性**：所有橙色用 #FF8C42，蓝色用 #66CCFF，保持与 App 一致
5. **语音优先**：核心卖点是「洛天依真人语音陪伴」，配音要清晰突出
6. **手机比例**：所有界面截图保持 9:16 竖屏，不做横屏适配
7. **节奏明快**：45 秒内完成，不拖沓，每 5 秒必须有画面变化
